### PR-VM-1: F2 ReplayResultViewModel wiring

**分支**: `feat/vm-replay-real-service`

**启动说明（给 VM Claude）**:

> 在 cloud branch `main` 已 ship 的 `MetBench_BLL.Core/SystemMT/Pipeline/ReplayContextBuilder.cs`
> 基础上，把 `MetBench_Client/ViewModels/ReplayResultViewModel.cs` 的
> `_demoClassification` 占位逻辑替换为真实 `ReplayService.ReplayAsync(ctx, original)`.
>
> 1. `MetBench_Client/App.xaml.cs` 加 DI:
>    ```csharp
>    services.AddScoped<ReplayContextBuilder>();
>    ```
> 2. `ReplayResultViewModel` 构造器加：`ReplayContextBuilder builder, ReplayService replayService`
> 3. 加 `[RelayCommand] async Task RunRealReplayAsync()`：
>    ```csharp
>    var built = _builder.Build(Anomaly!.IdAnomaly, _workingDir);
>    var original = ReconstructOutcomeFromResult(OriginalResult!);
>    var replay = await _replayService.ReplayAsync(built.Context, original);
>    ApplyReplayResult(replay);
>    ```
>    `ReconstructOutcomeFromResult` 私有方法把 `Result` 转成 `PipelineOutcome`（按 Result 字段直填）。
> 4. `ReplayResultPage.xaml` 加按钮 `Command="{Binding ViewModel.RunRealReplayCommand}"` 标 "Run real replay"
> 5. 保留 `SimulateReplay` 当 fallback（演示用）。

**结束条件**:
- [ ] `dotnet build MetBench_Client.csproj` 通过
- [ ] 启动 app → AnomalyListPage → 选 anomaly → 进 ReplayResultPage → 点 "Run real replay" → 不崩
- [ ] LiteDB ValidationRuns / Executions 表有新记录
- [ ] `_demoClassification` 还在但 UI 不再依赖它当主路径
- [ ] commit 推送 + 创建 PR 目标 main

**测试命令**:
```powershell

# 应 10/10 pass
```

**Commit 模板**:

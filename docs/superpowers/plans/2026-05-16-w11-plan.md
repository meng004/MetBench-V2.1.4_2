# W11 计划 — 2026-05-16 起

> 起点：`v2.1.0-rc1` (commit `eccb051`)
> 目标：让 v2.1 正式发版 + 启动论文实证补充 + 解锁 W12 路径
> 边界：UAT round-1 反馈到达前**不**改既有功能；W11 主线是**新增** + **响应**

---

## 工作流模式

W11 分三条并行轨道：

| 轨道 | 触发 | 负责人 | 边界 |
|------|------|--------|------|
| **🟢 UAT-driven** | 测试员交付 round-1 报告 / Issue | 开发负责人 | 修 Blocker / Major → round-2 |
| **🔵 论文 / 加分** | 排期，不等 UAT | cloud-side | 不改已 ship 接口 |
| **🟡 准备 W12** | 排期，不等 UAT | cloud-side | 写 RFC / 骨架，不实施 |

每条轨道独立 PR，CI 自动栅栏，互不阻塞。

---

## 🟢 UAT-driven 轨道（响应式）

### 准入

测试员 PR merged 进 `docs/uat/reports/round-1-*/`，对应 GitHub Issue 已开（label `uat-blocker` / `uat-major` / `uat-minor`）。

### 处置 SLA

| 严重度 | 响应时间 | 操作 |
|--------|---------|------|
| 🔴 Blocker | 当天 | 起 fix PR，CI 绿即 merge；触发 round-2 |
| 🟡 Major | 2 工作日 | 起 fix PR；可累积合并；累计 5 个或 round 结束触发 round-2 |
| 🟢 Minor | 1 周内 | 进 backlog，下版本前清理 |
| uat-doc | 当天 | 直接 PR 修文档 |
| uat-env | 立刻 | 改 setup-guide 或加 troubleshooting |
| uat-enhancement | 评估排期 | 决定本版进 / 下版进 |

### 触发 round-2 的条件

满足任一：

1. 任一 🔴 Blocker bug 已 fix
2. 累计 ≥ 5 个 🟡 Major fix
3. 距 round-1 ≥ 5 个工作日（强制时间盒）

每 round 闭环：fix → tag `v2.1.0-rcN` → 通知测试员重跑 → dashboard 追加一行。

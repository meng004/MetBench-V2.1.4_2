# MetBench bug inventory — real fix commits + synthetic mutants

> Single-table consolidation of all bugs MetBench's MR matrix evaluates.
> Two sources:
>
> 1. **Real (R)** — extracted from `mit-crpg/OpenMOC` or `openmc-dev/openmc`
>    git history (fix commits) or discovered live by MetBench's MR
>    matrix.
> 2. **Synthetic (S)** — `tools/mutations.py` Mut00-Mut47, deliberately
>    injected at known code points to stress-test the MR catalogue.
>
> Each row links to: the upstream commit / mutation ID, the affected
> file, predicted MetaPattern (MP) fit, which MR catches it (if any),
> and the live-detection state on the currently-installed solvers.
